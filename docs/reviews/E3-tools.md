# E3 review: the tool surface seen from an agent's side

**Session:** v2 E3 (14 November 2026). **Decisions:** [ADR 0045](../adr/0045-tool-review-and-the-tool-call-log.md).
**Companion:** [E3-evaluation.md](E3-evaluation.md), the script the owner runs in ChatGPT and Claude.
**Hard rule kept:** nothing here touched a live system. Every number comes from the real server running against the mock
LegendKeeper (`npx tsx scripts/tool-surface.ts`); the owner's bridge connector was never called.

## 1. What the tool list costs

Measured exactly as each client receives `tools/list` (name, title, description, input schema, annotations as JSON), once
per kind of profile. **Tokens are an estimate** (characters ÷ 4): schemas tokenise a little worse than prose, so read them as a
size, not a bill. Before = the surface at the start of this session; after = with the wording changes of this session.

Server instructions: 1235 characters (≈ 309 tokens).

- **ChatGPT at `propose` and Claude at `write` see the same 61 tools** (about 31,000 tokens now, 36,500 before). A `read` profile
  sees 28 (9,100 tokens now). The three low-level tools (`lk_api_list_operations`, `lk_api_describe_operation`,
  `lk_api_paginate_all`) appear only with the profile's "show low-level tools" setting.
- **The per-operation tools stay off** (`MCP_EXPOSE_PER_OP_TOOLS=false`, the default): 89 more tools and about 171,000 tokens.
- **The wording changes took about 15% off** (descriptions 50,000 → 36,000 characters; schema field descriptions 85,000 → 77,000).
  What is left is mostly structure: the 61 schemas are 77,000 characters, and the two map-feature schemas alone are 11,000
  (their `style` object lists LegendKeeper's enumerations). Going further without losing capability means fewer tools
  (section 3), not shorter sentences.
- **Lazy loading is the client's choice.** Some clients load tool definitions on demand (a keyword search, then the schema).
  A short, distinctive first sentence matters more there than in an eager client, because it is what the search sees. The
  new descriptions start with what the tool does, in the words an agent would search for.
- **The server instructions** (sent on connect) are now 1,235 characters (≈ 310 tokens): the guide first, then four rules.
  The bridge guide is read by section: "How to decide" is about 1,600 tokens; the whole guide is about 13,700.
